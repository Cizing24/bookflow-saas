# Roadmap

## Phase 1 — 核心與 MVP

已交付帳號 Session、多租戶與角色、建立店家、服務與人員管理、每週營業時間、公開預約、管理端預約列表、資料庫併發防重疊、Migration / Seed 與自動測試。實際驗證結果與限制以 STATUS.md 為準。

## Phase 2 — 排程與營運

- 員工個別班表、服務與員工對應、午休、多段營業時間、假日與請假。
- 明確的 DST 重複時間選擇與跨日營業政策。
- 預約取消、改期、可稽核狀態轉換、釋放時段與重試冪等鍵。
- Email 通知、驗證與密碼復原，寄信服務採 outbox / 可重試工作。
- 邀請成員、Owner / Admin / Staff 權限管理、人員與帳號綁定。
- 預約查詢、分頁、日期篩選與營收報表。

## 公開 Production 上線前

- 共享認證與公開 API 限流、可信任 Proxy / IP 政策、反濫用與必要的 CAPTCHA。
- HTTPS 與正式 Origin、Secrets 管理、資料庫最小權限、備份與還原演練。
- 顧客資料隱私政策、保留／刪除流程、監控、稽核與錯誤追蹤。
- 處理仍待上游修補的開發依賴安全告警，設定持續掃描。
- 在部署環境重新驗證 migration、併發、Session Cookie 與跨租戶隔離，再經明確授權上線。

## Phase 3 — SaaS 商業化

訂閱方案、計費與配額、自訂品牌、付款／訂金、權限細化、可觀測性與容量規劃。每項需有實際產品需求與獨立驗收條件。
